# 🌀 M3TH TOOLKIT
> A modular, privacy-centric reconnaissance framework for the modern terminal.

M3TH is a lightweight, command-line toolkit designed for OSINT, network testing, and AI-augmented intelligence. It features native Tor routing and seamless LLM integration.

## ✨ Features
- 🤖 **AI-Augmented Intel:** Integrated `venice` module for LLM-driven recon.
- 🕵️ **Advanced OSINT:** Pre-configured wrappers for Amass, Sherlock, and more.
- 🛡️ **Privacy First:** Built-in Tor routing (`VENICE_TOR=1`).
- 🛠️ **Modular Design:** Easy to extend with new scripts in the `/bin` directory.

## 🚀 Quick Start

### Prerequisites
Ensure you have `tor`, `curl`, and `python` installed on your system.

### Installation
```bash
git clone https://github.com/yourusername/m3th-toolkit.git
cd m3th-toolkit
chmod +x install.sh
./install.sh
